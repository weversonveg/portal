Configuração

Informe o repositório e a pasta onde os arquivos ficam. Os valores ficam salvos neste navegador.

Como configurar (passo a passo)
  1. Repositório: preencha no formato usuario/repo (ex.: weversonveg/portal).
  2. Branch: normalmente main (ou master).
  3. Pasta: onde os arquivos ficam (ex.: downloads).
  4. Lista: arquivo JSON que a página pública lê (ex.: downloads/lista.json).
  5. Para adicionar um arquivo: suba-o na pasta downloads/ pelo GitHub e adicione o nome no lista.json.
  6. Editar a lista por aqui: o botão “Editar lista” abre o arquivo no GitHub para você alterar e commitar. Para edição direta nesta página, seria necessário um backend (veja a nota abaixo).

Upload direto pela página exigiria um Personal Access Token do GitHub exposto no navegador (inseguro) ou um pequeno servidor/Action. Se quiser, posso te passar o workflow do GitHub Actions para publicar automaticamente a lista a cada arquivo novo.
