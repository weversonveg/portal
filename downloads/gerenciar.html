Configuração

Preencha os campos abaixo e clique em Salvar — os valores ficam guardados neste navegador e nunca vão para dentro dos arquivos publicados.

Como configurar (passo a passo)
  1. Projeto: acesse console.cloud.google.com e crie um projeto (ex.: Central de Downloads).
  2. Ativar API: em APIs e serviços → Biblioteca, procure e ative a Google Drive API.
  3. Tela de permissão: em Tela de permissão OAuth, escolha Externo, preencha nome e e-mails e salve (em modo teste, adicione seu e-mail como usuário de teste).
  4. Client ID: em Credenciais → Criar credenciais → ID do cliente OAuth, escolha Aplicativo da Web. Em Origens JavaScript autorizadas, adicione o endereço desta página de administração (ex.: https://seuusuario.github.io). Cole o ID no campo acima.
  5. Pasta no Drive: crie a pasta (ex.: Downloads do site), abra-a e copie o ID da URL drive.google.com/drive/folders/ID (ou cole a URL inteira — a página extrai o ID). Compartilhe a pasta como “Qualquer pessoa com o link” → Leitor para os arquivos aparecerem na página pública.
  6. Publicação: a página pública exibe os arquivos pela visualização da pasta; o botão de cadeado/globo da lista abaixo mostra se cada arquivo está privado ou público — clique no cadeado para publicar.
  7. Hospedagem: publique os dois HTML (esta página e a pública) em um serviço estático com HTTPS (GitHub Pages, Netlify, Vercel…). O login do Google não funciona em páginas file:// (funciona em localhost e https).

Notas: a categoria é gravada na descrição do arquivo no Drive (cat=…). Arquivos enviados direto pelo Drive precisam ser compartilhados manualmente (a página não altera arquivos que não foram enviados por ela — escopo drive.file); o mesmo vale para exclusão. Para permitir que só alguns e-mails usem esta página de administração, preencha ADMIN_EMAILS no código dela.
