Configuração do Google Drive

Os arquivos da pasta já ficam visíveis a todos os visitantes automaticamente (ID da pasta e Chave de API gravados no código, nas constantes DEFAULT_CONFIG do <script>). Os campos abaixo ficam salvos apenas neste navegador: só o Client ID é realmente necessário para você administrar (envio, exclusão). Para permitir que só alguns e-mails usem o Gerenciar, preencha ADMIN_EMAILS no código.

Como obter cada valor (passo a passo)
  1. Projeto: acesse console.cloud.google.com e crie um projeto (ex.: Central de Downloads).
  2. Ativar API: em APIs e serviços → Biblioteca, procure e ative a Google Drive API.
  3. Tela de permissão: em Tela de permissão OAuth, escolha Externo, preencha nome e e-mails e salve (em modo teste, adicione seu e-mail como usuário de teste).
  4. Client ID: em Credenciais → Criar credenciais → ID do cliente OAuth, escolha Aplicativo da Web. Em Origens JavaScript autorizadas, adicione o endereço onde esta página fica hospedada (ex.: https://seuusuario.github.io). Copie o ID para o campo acima.
  5. Chave de API: em Credenciais → Criar credenciais → Chave de API; recomenda-se restringi-la à Google Drive API. É ela que permite aos visitantes listar os arquivos públicos na aba Downloads.
  6. Pasta no Drive: crie a pasta (ex.: Downloads do site), abra-a e copie o ID da URL drive.google.com/drive/folders/ID para o campo acima.
  7. Hospedagem: publique este HTML em um serviço estático com HTTPS (GitHub Pages, Netlify, Vercel…). O login do Google não funciona em páginas file:// (funciona em localhost e https).
  8. Pronto: entre com a conta Google e envie os arquivos — cada envio é compartilhado automaticamente como “qualquer pessoa com o link” e passa a aparecer na aba Downloads.

Notas: a categoria é gravada na descrição do arquivo no Drive (cat=…). O botão de cadeado/globo na lista mostra se o arquivo está privado ou público — clique nele para tornar o arquivo visível na aba Downloads. Arquivos enviados direto pelo Drive precisam ser compartilhados manualmente (a página não consegue alterar arquivos que não foram enviados por ela — escopo drive.file). A exclusão pela página também só funciona para arquivos enviados por ela.
